# 로컬 작업 산출물

실험 코드와 확정 결과 사이에 생기는 빌드·전송·검증 파일을 이곳에 모은다. 이 폴더의 실제 산출물은 Git에서 제외되며 자동 삭제하지 않는다.

| 폴더 | 내용 |
|---|---|
| `presentation-builds/lab-20261014/` | Lab 최상위에 흩어져 있던 10월 14일 발표 빌드 10종 |
| `presentation-builds/labmeeting-history/` | 과거 발표 빌드, 초안 `output/`, 차트 임시 작업 파일 |
| `remote-transfer/2026-10/` | 데스크톱 전송 ZIP·분할 조각·받아온 결과 사본 |
| `exports/` | 전체 그래프 및 직접 RUL 결과 배포 ZIP |
| `maintenance/20261015-workspace-cleanup/` | 이동 전후 파일 해시, 원래 경로, 변경 전 문서, 검증 기록 |

새 작업도 이름 있는 하위 폴더에 저장한다. `results/`는 실험의 원본 결과, 이곳은 작업용 산출물이다.

발표 완성본은 [presentations/published](../presentations/published/)에 있다. 과거 빌드는 당시 도구 버전과 외부 참조에 의존할 수 있으며 모든 초안을 다시 실행한 것은 아니다. 이동 후 실행 위치와 경로 보정은 각 빌드 묶음의 README에 기록한다.
