# 과거 실험 보관

[cleanup-20261013](cleanup-20261013/README.md)은 2026-10-13 정리 시 보존한 과거 실험과 복구본이다. 2026-10-15에 `Documents/CodexBackups/`에서 이 프로젝트 하위로 옮겼다.

- `snapshot/`: 당시 코드·설정·문서·결과·가공 데이터 복사본.
- `retired/`: 현행 작업에서 분리한 T5·LoRA·strict-v2 실험 및 모델.
- 각 manifest와 과거 정리 기록은 원문 그대로 보존한다. 과거 절대경로는 당시 실행 이력이며 현재 위치를 뜻하지 않는다.

이 보관본은 로컬에 유지하며 Git에는 넣지 않는다. 최신 프로젝트 위에 전체를 덮어쓰지 말고 필요한 항목만 별도로 복구한다. 이번 이동의 원래 경로와 SHA-256 검증은 [정리 기록](../artifacts/maintenance/20261015-workspace-cleanup/)에 있다.
