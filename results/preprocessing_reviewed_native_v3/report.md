# 감사 후 SOH 데이터: reviewed_native_v3

2026-10-08 재검토를 반영한 새 버전이다. 원본 capacity_ah, Qref, SOH, cycle과 배터리 분할은 유지했다. 이전 strict_v2와 이전 예측 결과는 보존한다. 이 버전은 **원 제작자가 보고한 방전 용량을 예측하는 실험**이며, 계측 불확실성이 모두 해소됐거나 동일한 완전 충전 조건을 인증한 데이터라는 뜻은 아니다.

## 판정 변경

- **NASA**: 충전 로그가 없지만 방전 용량과 파형 대조를 통과한 B0005/6/7의 cycle 90을 유지한다. 충전 로그 부재는 검토 표시로 남는다. 새 유효 관측 3개, 전체 636개.
- **MIT**: native QDischarge를 목표 용량의 기준으로 사용한다. CV 구간에서 원시 전류 적분과 카운터가 일치하지 않는 문제는 원인 미확정 상태이며, 적분 차이만으로 용량을 제외하거나 적분값으로 원본을 교체하지 않는다. 원본 summary와 Qd 카운터의 일치는 내부 기록 대조이며 독립적인 물리 교정 검증이 아니다.
- **MIT 기록 공백**: 샘플 간격이 max(60초, 정상 양의 간격 중앙값의 10배)를 넘으면 그 공백을 적분하지 않는다. 결과는 관측된 구간의 진단 적분이지 공백까지 복원한 완전한 용량이 아니다. 시작부 파형이 일부 기록되지 않은 경우도 native 카운터의 용량 오류로 자동 판단하지 않는다.
- **MIT 복수 방전**: 가장 긴 한 구간만 택하지 않고 모든 방전 조각을 확인한다. 조각 사이 카운터 재설정과 재충전을 검사한다. Batch 1에서 18개, Batch 3에서 9,865개를 유지하도록 변경했다. 이전에 유효했던 b2c32 cycle 249는 조각 사이 카운터 재설정으로 제외했고, b3c5/22/38의 cycle 191/884/829는 충방전 혼재와 충전 종료 조건 때문에 제외했다. 기존 적분 보류였던 다른 2건도 충방전 혼재로 계속 제외된다. 신규 제외는 총 4개다.
- **CALCE/XJTU**: 원시 기록에서 확인한 불완전 충·방전 및 기타 제외 사유를 유지한다. 제작자 noisy MIT 채널 6개, 미측정 placeholder, XJTU 초기 별도 진단 프로토콜도 기존대로 정답에서 제외한다.

원본 shape의 급락·반등을 이유로 용량을 깎거나 평활화하지 않았다. 모델 결과를 보고 QC 임계값을 고르지 않았다. [관측별 변경 내역](reclassified_observations.csv), [정책](policy.json), [검증 기록](verification.json).

## 64→1 입력과 정답

입력은 원래 위치 **t-64~t-1**, 정답은 유효한 **y_t** 하나다. 제외된 과거 관측은 같은 위치에 NaN을 넣어 C2의 기본 결측 마스크로 처리한다. 숫자로 채우거나 제외된 행을 지우지 않는다. 알려진 cycle 누락·기록 구간 경계는 계속 창을 끊는다. 선형 기준선 계산을 위해 최소 2개 유효 입력을 요구하며, 실제 실험의 최소 유효 입력은 50~64개였다.

이전의 “64개가 모두 유효해야 함”과 평가 집합이 다르다. 이전 strict_v2 점수와 새 점수의 차이를 전처리만의 개선 효과로 주장하지 않는다. 동일한 새 입력·정답에서 LastValue, Linear, C2 zero-shot, C2 head-only를 비교한다.

| 실험군 | 기존 유효 용량 → 새 유효 용량 | 이전 완전 입력 64→1 | 새 결측 허용 64→1 | 최소 유효 과거 / 64 |
|---|---:|---:|---:|---:|
| NASA | 633 → 636 | 185 | 380 | 64 |
| XJTU 2C | 3,209 → 3,209 | 2,697 | 2,705 | 63 |
| XJTU 3C | 3,727 → 3,727 | 2,767 | 2,782 | 63 |
| CALCE | 3,801 → 3,801 | 191 | 3,549 | 57 |
| MIT Batch 1 | 38,728 → 38,746 | 35,090 | 35,862 | 50 |
| MIT Batch 2 | 24,898 → 24,897 | 20,625 | 21,825 | 61 |
| MIT Batch 3 | 31,371 → 41,233 | 26,139 | 38,673 | 63 |

위 창 수는 **train/test 분할 전 모든 기록** 기준이다. 모델 결과나 테스트 수가 아니다. 테스트 전용 수와 점수는 [64→1 재실험 보고서](../c2-battery/one-step-64-reviewed-v3/report.md)에 기록한다.

CALCE의 축은 보존된 관측 순서이며 파일 간 미기록 물리 cycle 수는 알 수 없다. MIT continuation은 물리 배터리 식별자를 공유하며 source/test로 갈라지지 않는다. 기존 평가와 같이 배치별 기록의 경계에서 입력창을 다시 시작하므로 모든 물리 수명 시점을 예측했다는 뜻은 아니다.

## 검증과 재현

- 모든 원본 파일 해시를 부모 manifest와 대조했고, 새 bundle을 다시 로드해 Q·SOH·cycle 및 Qref 일치를 확인했다.
- 파형 특징을 추출한 실행과 판정 규칙을 적용한 실행의 해시를 따로 남겼다. 학습 프로토콜을 고정하기 전, 파형 시작부 누락을 제외가 아닌 검토 표시로 분리하는 판정 수정이 한 번 있었다. 원시 파형 특징은 체크섬을 확인해 재사용했고 초기 candidate manifest는 `.runtime`에 보관했다.
- 학습 프로토콜이 존재하면 `--classify-cached`로 데이터를 다시 판정할 수 없게 했다. 실험 이후 정책을 바꾸려면 별도 버전을 만들어야 한다.
- 결측이 처음·중간·마지막에 있는 입력, 제외 정답, 실제 cycle 누락, 미래값 변경, 긴 시간 공백, 방전 조각 사이 카운터 reset, 재충전 및 원시 카운터 불일치에 대한 회귀 테스트를 추가했다.
