# CALCE 64→16 zero-shot

4개 배터리의 시간순 관측, stride 1. 두 모델의 입력·창 설정과 baseline 점수 일치를 확인했다. 각 기록의 관측 기간을 3등분한다. R²는 한 예측창의 미래 실제 평균을 기준으로 계산한 뒤 해당 구간/전체의 유효 창을 단순평균하고 배터리 점수를 동일 가중 평균한다. 상수 창은 제외하며 음수는 유지한다.

파일 경계는 연결하지만 누락·불완전 관측은 연결하지 않는다. 달력 시간 휴지는 cycle 입력에 추가하지 않는다. 기존 32→8보다 horizon과 평가 창이 달라 점수 증감을 모델 개선으로 해석하지 않는다.
